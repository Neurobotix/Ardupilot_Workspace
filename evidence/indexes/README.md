# Evidence Indexes

This directory holds active indexes that route readers to reviewed evidence,
specialized asset/config inventories, and legacy curated evidence references.

## Naming

- Active indexes use stable `lower_snake_case.md` names.
- Examples: `evidence_catalog.md`, `asset_index.md`,
  `parameter_config_index.md`.
- Date prefixes are not required for active indexes.
- Historical imported index files may keep their original names when preserving
  provenance is safer than cosmetic cleanup.

Update the relevant index when a new evidence report becomes a canonical record
for a policy, claim, asset set, or operational proof.
