# Evidence Templates

This directory holds reusable report and promotion templates. Templates are not
evidence results and do not support status claims on their own.

## Naming

- Template files use stable `lower_snake_case.md` names.
- Examples: `launch_runtime_smoke_report.md`,
  `campaign_result_report.md`, `evidence_promotion_checklist.md`.
- Date prefixes are not required for templates because they are living forms,
  not event records.

When a template is filled out as a result report, save the filled report under
`evidence/reports/` using `YYYY-MM-DD_lower_snake_case.md`.
