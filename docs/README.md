# Docs

Human-facing current documentation belongs here. Use this tree for operating,
configuring, troubleshooting, and understanding the workspace.

Presentation templates for human-facing project communication live under
`docs/presentations/`.

## Naming

- Stable living docs use `lower_snake_case.md`.
- Examples: `quick_start.md`, `migration_status.md`, `workspace_map.md`.
- Do not add date prefixes to stable docs. Use modified-time sorting when a
  recent-doc view is needed.
- Historical or superseded docs belong under `docs/archive/` and keep their
  provenance names unless a reviewed migration updates every reference.

See `governance/standards/naming.md` for the workspace-wide policy.
