# Shahin-E SITL Model: Where Every Number Comes From

Status: Stage 1 written 2026-10-13. Not flown yet. Gates 0-5 below decide whether it is usable.

Files:

- `assets/models/shahin_e/model.sdf` (generated by `scripts/dev/gen_shahin_e_model.py`; never hand-edit)
- `assets/models/shahin_e/model.config`
- `assets/worlds/shahin_e_runway.sdf` (copy of `mini_talon_gps_airspeed_runway.sdf` with the model swapped)
- `config/vehicles/shahin_e.parm` (load alone, no `plane_base.parm`)

Source labels: **LOG** = real flight log 2025-12-30 (Shahin-E). **ENG** = engineers. **PHOTO** = photos of the aircraft.
**EST** = estimate, checked by Gate 5. **KNOB** = tuned at Gate 3 only.

## 3. Aerodynamics (flat-plate LiftDrag surfaces)

| Item | Value | Source |
| --- | --- | --- |
| Wing lift slope | 5.23 /rad | finite-wing formula, aspect ratio 9.9 |
| Wing a0 | 0.116 rad | **KNOB 1**, start value: gives CL 0.98 at 4.1 deg pitch, 17 m/s, 11 kg |
| Wing drag slope (cda) | 0.60 | assumption L/D ~ 8.6 at cruise (drag ~12.5 N). Checked later by the power-off glide |
| Wing stall | 0.25 rad incl. a0 (CLmax ~ 1.3) | EST; gives stall ~14.8 m/s at 11 kg, ~13.4 m/s at 9 kg (param AIRSPEED_STALL 13) |
| Tail lift slope | 4.19 /rad | finite-wing formula, aspect ratio 4 |
| Tail a0 | -0.06 rad | approximates wing downwash at the tail |
| Control effectiveness | aileron 1.5, flap 1.8, elevator 1.8, rudder 1.5 per rad | EST (flap-effectiveness theory, reduced for 3D) |
| Propeller | Mini Talon blade surfaces, unchanged | copied; real prop unknown |
| Motor full-throttle speed | 1310 rad/s | **KNOB 2**, start value: ~54 % throttle for ~12.5 N at 17 m/s |

Change from the earlier plan: knob 2 is now motor thrust, not drag. Motor and propeller are both
unknown, so thrust is the honest free value. Drag stays tied to a physical assumption (L/D) that the
power-off glide in the next calibration flight checks independently. When the engineers send the
motor (kV) and battery, knob 2 can be cross-checked: full speed in rad/s ~ kV x volts x 0.105.

## 4. Servo mapping (from LOG params, channel = SERVOn - 1)

| Output | Function | Range, trim | Model joint |
| --- | --- | --- | --- |
| SERVO1 | Aileron, reversed | 1100-1900, 1554 | left aileron (assumed side) |
| SERVO6 | Aileron | 900-2150, 1426 | right aileron (assumed side) |
| SERVO2 / SERVO7 | Elevator | 800-2200, 1433 | left / right elevator |
| SERVO3 / SERVO8 | Flap, reversed | 1300-1800 | left / right flap (1800 = up) |
| SERVO5 | Rudder | 950-2200, 1500 | rudder |
| SERVO11 / SERVO12 | Throttle left / right | 1100-2000 | left / right motor |

Joint directions are unverified until Gate 1. If a surface moves the wrong way, the fix is a sign
flip of that `<multiplier>` in the model. Never change SERVO params.

## 5. Parameters

`config/vehicles/shahin_e.parm` = the 1104 log params minus 569 hardware-specific ones (compass
and IMU calibration, sensor IDs, ports, OSD, battery wiring, fence, board trim; the full list is at
the end of the file), plus a short SITL section (JSON backend, simulated airspeed, calm SITL wind,
SITL battery). All flight, navigation, TECS, limits, takeoff, landing and servo params are unchanged.

Other observations: COMPASS_MOTCT is 0 (no motor-current compensation configured on the real aircraft),
EK3_IMU_MASK is 1 (one IMU used), LOG_REPLAY is 1 but the log has no EKF3 messages.

## 6. Success criteria (fixed before building)

| Gate | Pass condition |
| --- | --- |
| 0 | Mini Talon `plane-gps` still flies as before |
| 1 | Every surface and motor moves the right way on the ground |
| 2 | Takes off and completes an AUTO mission, no oscillation, no crash |
| 3 | At 17 m/s: throttle 54 % +/-5, pitch 4.1 deg +/-1 (KNOB 1 and 2 only) |
| 4 | Untuned (targets from the whole flight, mixed altitude and battery state): climb 0.9 m/s -> throttle 58 % +/-5, pitch 5.9 +/-1.5. Descent 0.5 m/s -> throttle 54 % +/-5, pitch 1.9 +/-1.5 |
| 5 | GPS-denial result changes < 20 % when tail area +/-30 %, CG 20-30 %, inertia +/-30 %, mass 9 / 13 kg |
